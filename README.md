## О проекте

**GreenBoard** — графическая панель управления видеокартой под Linux. Задумывался
как удобный «пульт», которого не хватает на Linux: вместо набора консольных
утилит (`nvidia-smi`, `nvidia-settings`, `dkms`, `pacman`) — одно окно.

> ⚠️ **Не аффилирован с NVIDIA Corporation.** Это независимый проект.
> Названия и торговые марки (NVIDIA, GeForce, NVENC и др.) принадлежат своим
> владельцам и упоминаются только для обозначения совместимости.

**Текущее состояние:** реализован **реальный мониторинг** (чтение данных GPU через
`nvidia-smi` каждые 0.5 с: температура, частоты, питание, вентиляторы, память,
загрузка, процессы). Остальные вкладки («Питание», «Профили», «Запись») — пока
мокап/заглушки; «Драйвер» показывает реальную версию драйвера и `dkms status`.

## Возможности (цель)

| Модуль | Что делает | Готовность |
|---|---|---|
| **Драйвер** | версия установленного/доступного драйвера, сборка под каждое ядро (DKMS), headers, проверка обновлений и обновление через pacman | 🔲 план |
| **Мониторинг** | температура, частоты, потребление, вентиляторы, загрузка (через NVML/nvidia-smi) | ✅ реальный |
| **Мощность** | лимит мощности (TDP) | 🔲 план |
| **Разгон/вентиляторы** | fan-curve и офсеты частот (Xorg, coolbits) | 🔲 план |
| **Профили** | сохранённые наборы настроек, применение при запуске | 🔲 план |
| **Запись/оверлей** | запись экрана через NVENC, оверлей fps/температуры | 🔲 план |

## Как это устроено (архитектура)

GreenBoard не управляет железом напрямую — это **обёртка над системными
инструментами Linux**:

```
┌─────────────┐   ┌──────────────────────────────────┐
│ GreenBoard  │──▶│ nvidia-smi / nvidia-settings /   │
│ (PySide6)   │   │ pynvml (NVML) / dkms / pacman    │
└─────────────┘   └──────────────────────────────────┘
```

- **Мониторинг/лимит мощности** — NVML (`pynvml`) + `nvidia-smi`;
- **Fan/разгон** — `nvidia-settings` (нужен `coolbits`, работает полноценно на Xorg);
- **Драйверы** — `pacman` + `dkms` + `mkinitcpio` (проверка/обновление/пересборка);
- **Запись/оверлей** — NVENC (`ffmpeg`/OBS), на Wayland — через PipeWire/dma-buf.

## Вкладки (текущий мокап)

- **📦 Драйвер** — карта, версия драйвера, ядро, статус сборки под ядра (DKMS),
  наличие headers, кнопки «Проверить обновления» / «Обновить драйвер».
- **📊 Мониторинг** — температура, частоты GPU/памяти, потребление, вентиляторы, загрузка.
- **⚡ Мощность/Разгон** — слайдер лимита мощности; примечание про Xorg-only функции.
- **🎮 Профили** — «Тихий / Игры / Макс. производительность» с кнопкой «Применить».
- **🎥 Запись** — оверлей и запись (заглушки).

## Дорожная карта

- **M0 — исследование**: определить поколение карты (`lspci`), установленные
  пакеты, `dkms status`, поведение `nvidia-settings` на Wayland/Xorg.
- **M1 — Драйвер (read-only)**: показ версий и статуса сборки под ядра, без изменений.
- **M2 — Мониторинг + лимит мощности**: реальные данные через NVML.
- **M3 — Разгон/вентиляторы + профили** (Xorg, coolbits).
- **M4 — Обновление драйвера, запись/оверлей**.

## Запуск мокапа

```bash

pip install PySide6
python app.py
```
